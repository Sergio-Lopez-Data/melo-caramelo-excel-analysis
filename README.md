# 📈 Análisis de Ventas — Melo Caramelo | Sales Analysis

> **ES** | Análisis completo de ventas para una empresa de confitería usando Excel: limpieza de datos, fórmulas avanzadas, tablas dinámicas y dashboard ejecutivo.  
> **EN** | Full sales analysis for a confectionery company using Excel: data cleaning, advanced formulas, pivot tables, and executive dashboard.

---

## 🇪🇸 Español

### Descripción del proyecto
Análisis de datos de ventas de **Melo Caramelo**, empresa ficticia del sector de confitería. El objetivo fue transformar datos crudos de transacciones en un dashboard ejecutivo que permita tomar decisiones comerciales basadas en datos.

### Problema que resuelve
¿Cuáles son los productos más rentables? ¿En qué períodos se concentran las ventas? ¿Qué categorías tienen mayor rotación? Este análisis convierte una hoja de datos transaccionales en respuestas concretas para el equipo comercial.

### Herramientas y técnicas usadas
- **Excel** — Limpieza de datos, validación y estandarización
- **Fórmulas avanzadas** — BUSCARV, SUMAR.SI.CONJUNTO, TEXTO, SI anidados
- **Tablas Dinámicas** — Segmentación por producto, período y categoría
- **Dashboard** — Visualización ejecutiva con gráficos dinámicos y slicers interactivos

### Estructura del archivo
El archivo contiene:
- Hoja de datos crudos (raw data)
- Hoja de datos limpios y transformados
- Tablas dinámicas de análisis
- Dashboard ejecutivo final con gráficos interactivos
- Reporte PDF con hallazgos y conclusiones

### Insights principales
- Identificación de productos de mayor y menor rentabilidad
- Análisis de tendencias de ventas por período
- Segmentación de categorías por volumen de ventas

## 🇺🇸 English

### Project Description
Sales data analysis for **Melo Caramelo**, a fictional confectionery company. The goal was to transform raw transaction data into an executive dashboard enabling data-driven business decisions.

### Problem it solves
Which products are most profitable? When do sales peak? Which categories have the highest turnover? This analysis turns transactional data into concrete answers for the sales team.

### Tools & Techniques
- **Excel** — Data cleaning, validation, and standardization
- **Advanced formulas** — VLOOKUP, SUMIFS, TEXT, nested IF statements
- **Pivot Tables** — Segmentation by product, period, and category
- **Dashboard** — Executive visualization with dynamic charts and interactive slicers
