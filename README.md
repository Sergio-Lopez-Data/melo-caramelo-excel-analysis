# Dashboard de Ventas – Melo Caramelo

Análisis y visualización de datos de ventas para cliente del sector comercial.

## Herramientas utilizadas
- Microsoft Excel (avanzado)
- Power Query (limpieza y transformación de datos)
- Tablas dinámicas
- Dashboard interactivo

## ¿Qué hice?
- Limpieza y estandarización de datos en crudo
- Transformación y modelado con Power Query
- Construcción de tablas dinámicas para análisis de ventas
- Diseño de dashboard con indicadores clave (KPIs) para toma de decisiones

## Archivos
- `MeloCaramelo_v3_final.xlsx` — archivo Excel con el análisis completo y dashboard
- `Reporte_Final_Melo_Caramelo.pdf` — reporte ejecutivo del análisis
